# DSL 명세

`tex_to_dsl.py` 가 내고 `make_hwp_from_txt.py` 가 읽는 중간 형식. UTF-8 텍스트, **한 줄에 명령 하나**, `명령:` 뒤에 인자. 손으로 고쳐도 된다.

## tex_to_dsl.py 가 생성하는 명령

| 명령 | 뜻 | 비고 |
|---|---|---|
| `PROB: 라벨` | 문제 시작. 굵은 제목 문단 | 앞 문제와의 간격은 `--prob-gap` |
| `TEXT: 본문` | 본문 텍스트 | 뒤쪽 공백 보존. 인라인 수식 앞뒤에서 나뉜다 |
| `EQ: <LaTeX>` | 줄 안 수식 | 한글 수식 객체(글자처럼 취급) |
| `EQD: <LaTeX>` | 독립 행 수식, 가운데 정렬 | 여러 줄 환경은 한 줄로 접혀 들어온다 |
| `BR:` | 문단 나누기 | 연속 `BR:` 은 하나로 정리됨 |
| `SOL:` … `ENDSOL:` | 해설 블록 | 기본 미주. `--solutions inline` 이면 본문 |
| `SEC: 제목` | 굵은 절 제목 | `--solutions inline` 일 때 "해설" 표시로 씀 |
| `GOTO: N` | 기존 hwp 의 `N.` 문항 헤더 뒤로 커서 이동 | `--attach` 전용. 바로 뒤에 `SOL:` 이 온다 |
| `FIX: 메모` | 작업 메모. **문서에 들어가지 않음** | `% [그림 필요: …]` 주석이 여기로 온다 |
| `NEWPAGE:` | 쪽 나누기 | |

## make_hwp_from_txt.py 가 추가로 이해하는 명령

손으로 DSL 을 다듬을 때 쓸 수 있다.

| 명령 | 뜻 |
|---|---|
| `IMG: 경로 \| 폭mm` | 그림 삽입(파일이 있어야 함). `\| 폭` 생략 가능 |
| `FIG: 번호 \| 설명 \| 70x50` | 그림 자리표시자(아직 그림이 없을 때). 크기는 `폭x높이` mm, 생략 시 70x50. 나중에 `IMG:` 로 바꾼다 |
| `EQALIGN:` … `END:` | 여러 줄 수식. `&` 정렬, 줄은 개행 |
| `ALIGN: left\|center\|right\|justify\|distribute` | 이후 문단 정렬 |
| `INDENT: left=10 first=-10` | 왼쪽 여백 / 첫 줄 들여쓰기 (mm) |
| `EXAM: 6・1 \| 제목` | 해설편식 예제/문제 제목 |
| `SOURCE: 출처` | 오른쪽 정렬 출처 |
| `ANS:` | `……〔답〕` 표시 |
| `UNSURE: 원문` | 판독 불명 표시 |
| `SPACE:` | 공백 한 칸 (구버전 호환) |
| `HLINE:` `TREE:` `BOX:` `ENDBOX:` | 아직 미구현. 문단만 나눈다 |

모르는 명령은 건너뛰고 마지막에 "알 수 없는 DSL 명령" 으로 개수를 출력한다.

## 규칙

* `PROB:` / `SOL:` 은 자체 문단을 만든다. 그 직후의 `BR:` 과 `ENDSOL:`/`PROB:` 직전의 `BR:` 은 `tex_to_dsl.py` 가 미리 빼 둔다(미주 첫 줄이 비면 안 되므로).
* `SOL:` 이 열린 채 `PROB:` 를 만나면 `ENDSOL:` 이 없어도 미주를 닫는다.
* 수식 뒤에 오는 `TEXT:` 가 한글로 시작하면 붙여 쓰고(조사: `A가`), 그 외에는 공백을 넣는다 (`--no-auto-space` 로 끔). 한글인데 띄어야 하면 `TEXT:  정사면체` 처럼 공백을 하나 더 둔다.
* `EQD:` 앞뒤 문단은 자동으로 정리되므로 DSL 에서 `BR:` 을 붙여도 되고 안 붙여도 된다.

## 예

```
PROB: 예제 3-1. 연의 총수
TEXT: 두 종류의 문자
EQ: a,b
TEXT: 를 사용하여 …
BR:
EQD: n>m\ge2
SOL:
TEXT: 첫 번째 방법 …
ENDSOL:
```

전체 예시는 [examples/Sample_dsl.txt](../examples/Sample_dsl.txt).
